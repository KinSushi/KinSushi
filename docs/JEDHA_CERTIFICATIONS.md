## Purpose

This file documents the public certification logic behind the GitHub portfolio.

It is not a CV and not an application document. It is a technical/certification map used to keep the public GitHub profile aligned with the Jedha training path and the target employability domains: DataOps, Data Engineering, Data Science, MLOps and AI governance.

## RNCP35288 six-block portfolio mapping

| Block | Portfolio evidence to produce | Banking-market signal |
|---|---|---|
| Bloc 1 — Infrastructure data | Ingestion, storage, SQL schema, data lake / warehouse logic, data quality controls | Data Engineering / DataOps foundation |
| Bloc 2 — EDA and statistics | EDA notebooks, statistical tests, business KPI analysis, anomaly exploration | Data Analyst / Risk Analytics foundation |
| Bloc 3 — Machine learning | Supervised/unsupervised ML, fraud/risk/churn model, metrics, explainability | Data Scientist / ML Engineer foundation |
| Bloc 4 — Deep learning / NLP | Text classification, NLP, document intelligence or LLM/RAG prototype | AI / NLP / GenAI foundation |
| Bloc 5 — Industrialization | MLflow, Docker, API, dashboard, tests, monitoring | MLOps / ML Platform foundation |
| Bloc 6 — Data project leadership | Project charter, architecture, risk register, model card, data card, runbook | Project ownership / governance signal |

## Recommended public wording

Use this wording on GitHub:

> Jedha Data Science & AI — RNCP35288 Level 6 six-block certification track, with a public portfolio focused on data infrastructure, EDA/statistics, ML, NLP, MLOps and project governance.

For the Level 7 path, use conservative wording until the exact contract / registration code is confirmed in official school documents:

> Continuing toward RNCP Level 7 AI architecture competencies: data/AI governance, AI infrastructure, data pipelines for AI, MLOps and LLMOps.

Avoid overclaiming:

- Do not write “Architecte IA certified” until the full Level 7 certification is validated.
- Do not write a specific RNCP code unless it matches the official enrollment/assessment documents.
- Do not write “master” or “engineering degree”; RNCP Level 7 is a professional certification level, not a university degree by itself.

## Public GitHub rule

GitHub should show evidence, not administrative paperwork.

Public GitHub should contain:

- sanitized project evidence;
- technical documentation;
- architecture diagrams;
- model cards and data cards;
- runbooks;
- stack maps;
- synthetic datasets.

Public GitHub should not contain:

- application letters;
- CV variants;
- employer-specific strategy;
- salary targets;
- private school documents;
- certificates with personal IDs;
- contracts, invoices or CPF documents.
