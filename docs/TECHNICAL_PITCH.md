# Technical Pitch

This document defines the employer-neutral technical pitch supported by the public portfolio.

It is not a cover letter and not an interview script.

It includes a Linux/KVM infrastructure lab, a production-style Python API pipeline, and planned banking-data projects covering PostgreSQL data quality, reconciliation, fraud/risk MLOps, data migration and secure RAG.
