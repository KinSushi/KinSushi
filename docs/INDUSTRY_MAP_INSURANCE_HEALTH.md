## Purpose

This file extends the public GitHub profile beyond banking and big tech. It maps the Swiss insurance, health-insurance, reinsurance, pharma and medtech ecosystem.

The goal is to show that the same DataOps / MLOps profile is relevant for regulated data environments beyond finance.
