## Public principle

This documentation is technical evidence. It is not an application dossier.

Public GitHub should contain:

- architecture;
- stack maps;
- sanitized technical projects;
- runbooks;
- data/model governance templates;
- reproducible portfolio evidence.

Public GitHub should not contain:

- CV variants;
- cover letters;
- job trackers;
- salary targets;
- employer-specific application notes;
- private school documents;
- identity or administrative material.
