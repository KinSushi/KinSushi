# Certification Roadmap

This document keeps certification planning aligned with the public technical portfolio.

It is not a claim of certification completion. Only completed certifications should be claimed as completed on a CV or profile.

---

## Principle

Certifications should support technical evidence, not replace it.

Public portfolio priority:

1. runnable DataOps evidence;
2. runnable MLOps evidence;
3. sanitized Jedha evidence;
4. migration-quality evidence;
5. secure RAG evidence.

## Rule for public GitHub

Allowed:

- certification map;
- public links;
- study roadmap;
- technical evidence tied to certification skills.

Not allowed:

- private certificates with personal IDs;
- school documents;
- invoices;
- CPF documents;
- claims of completion before validation.
