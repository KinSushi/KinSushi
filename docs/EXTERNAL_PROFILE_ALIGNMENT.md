# External Profile Alignment

This document defines employer-neutral public wording for external profiles such as LinkedIn.

It is not a CV, not a cover letter and not a job application.

---

## Public headline option

```text
Junior Data / MLOps Engineer | Python · SQL · DataOps · MLflow · Docker · Monitoring | Regulated Finance & Swiss Data Platforms
```

---

## Public about-section structure

Use this structure outside GitHub:

1. One sentence on Data / MLOps positioning.
2. One sentence on regulated finance and large-scale systems.
3. One sentence on core stack: Python, SQL, Linux, Docker, MLflow, CI/CD.
4. One sentence on public portfolio evidence.
5. One sentence on Swiss target geography.

Do not include:

- salary targets;
- company-specific applications;
- recruiter notes;
- private school documents;
- long-term compensation ambitions;
- trading bot language.

---

## Featured project order

When the repos exist, use this order:

1. `banking-dataops-monitoring`
2. `fraud-mlops-control-tower`
3. `sovralys-infra-lab`
4. `pty-flights-pricing`
5. `secure-wealth-rag-assistant`

---

## Public tone

Prefer:

> I build reliable data and ML systems for regulated and large-scale environments.

Avoid:

> I am applying to a specific bank.

Prefer:

> DataOps, MLOps, model governance, data quality and production monitoring.

Avoid:

> Trading bot, live-trading performance, salary projection or company-specific targeting.

---

## Boundary

External profile strategy may be public only at the generic positioning level.

Actual CV variants, recruiter messages and application notes must stay private.
