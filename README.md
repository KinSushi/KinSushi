This GitHub is intentionally technical and employer-neutral. It is built to speak to Swiss banking, insurance, fintech, pharma/life sciences, health data, retail/e-commerce, industry, logistics, energy, public sector, consulting, research, cloud/platform teams and Swiss scale-ups.
